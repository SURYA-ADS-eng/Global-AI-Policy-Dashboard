# 🌍 Global AI Policy Dashboard

## 📌 Problem Statement

AI policies are being introduced and updated rapidly across countries, but the information is often scattered across different sources. This makes it difficult to **compare countries, track policy trends, identify regulatory risks, and understand AI policy maturity**.

## 💡 Solution

The **Global AI Policy Dashboard** is an interactive Data Analytics and Machine Learning dashboard developed to centralize and analyze global AI policy data.

It provides **country-wise comparisons, policy trends, risk analysis, sentiment analysis, benchmarking, and ML-based policy maturity prediction** through an interactive Streamlit application.

## ✨ Key Features

* 📊 Interactive policy analytics dashboard
* 🌍 Country-wise policy comparison
* 📈 Policy trend & time-series analysis
* 🏆 Country benchmarking and ranking
* ⚠️ Regulatory risk analysis
* 💬 Policy sentiment analysis
* 🤖 AI Policy Maturity prediction using Machine Learning
* 📥 Interactive data-driven insights

## 🛠️ Tech Stack

**Python | Pandas | NumPy | Scikit-learn | Plotly | Matplotlib | Streamlit | Git | GitHub**

## 🤖 Machine Learning

A **Random Forest Regression** model is used to predict the **AI Policy Maturity Score** based on relevant policy indicators.
